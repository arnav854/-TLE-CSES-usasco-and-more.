#  DSA Practice Repository(TLE-CSES-usasco-and-more)

This folder contains a collection of C++ solutions and practice materials for competitive programming and data structures & algorithms study.

## Overview

The repository is organized into two main areas:

- TLE problem solutions under the tle folder
- USASCO training content under the usasco folder

## Structure

### tle/1300
Contains solutions for problems in the 1300-level range, including files such as:

- average_sleep_time.cpp
- buying_shovels.cpp
- divide_and_equalize.cpp
- divisible_pairs.cpp
- find_the_different_ones.cpp
- most_socially_distanced_subsequence.cpp
- product_of_three_numbers.cpp
- romantic_glasses.cpp
- shuffle.cpp
- simple_strings.cpp

### usasco
Contains practice materials grouped by difficulty and topic:

- advanced/
- bronze/
- gold/
- platinum/
- silver/

The silver section also includes folders for prefix sums and sorting/searching topics.

## Purpose

This repository is intended for:

- practicing competitive programming
- improving problem-solving skills
- reviewing C++ implementations for common algorithms and contest problems

## Notes

Most files are written in C++ and are suitable for use with competitive programming workflows.
